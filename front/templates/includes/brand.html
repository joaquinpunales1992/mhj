{% comment %} The single source of truth for type and colour. Every template previously declared its own palette and font link, which is how the site ended up with a stray teal on the home page, three different font-weight sets, and 46 distinct hex values on the property page. Include this in and use the custom properties below instead of literals. Templates that predate this (home.html via the HTML5UP theme, contact_seller.html) still carry their own rules; the tokens here are deliberately identical to the values those files already use, so including it changes nothing visually and new work can reference tokens instead of copying hexes. {% endcomment %}
